CUSTOM DEEPSEEK / AI ENDPOINT CONFIGURATION

Edit /opt/telecom-copilot/.env:

DEEPSEEK_BASE_URL=https://YOUR-PROVIDER-BASE-URL/v1
DEEPSEEK_API_KEY=YOUR_KEY
DEEPSEEK_MODEL=THE_MODEL-NAME-GIVEN-BY-YOUR-PROVIDER

The application automatically calls:
  <DEEPSEEK_BASE_URL>/chat/completions

If your provider gives the complete URL ending in /chat/completions, you may put that full URL in DEEPSEEK_BASE_URL and it will be used as-is.

Examples:
  Base URL supplied: https://gateway.example.org/v1
  Actual request:    https://gateway.example.org/v1/chat/completions

  Full URL supplied: https://gateway.example.org/v1/chat/completions
  Actual request:    https://gateway.example.org/v1/chat/completions
